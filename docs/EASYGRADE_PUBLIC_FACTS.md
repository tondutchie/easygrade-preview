## Rules

1. Public copy must not contradict this file.
2. If a fact is not verified here, keep it `TBC`; do not infer or invent it.
3. New public facts must be added here before or in the same change that publishes them.
4. Marketing, website, docs, GitHub, release notes, video descriptions, social copy, marketplace copy, and third-party-facing material must stay consistent.
5. Claims about performance, compatibility, pricing, availability, or superiority require explicit evidence and approval.
6. If copies of this file exist in multiple EasyGrade repositories, they must remain byte-identical.
7. If a mismatch is found, stop public-content work and synchronize the files before publishing.

## Claim policy
- Do not claim “best”, “fastest”, “industry-leading”, “professional-grade”, or similar superiority without approved evidence.
- Do not publish benchmark numbers without test hardware, resolution, host/version, test state, methodology, and approval.
- Engineering test results are not automatically marketing claims.
- Do not publish sample/dev prices as real prices.
- Do not publish fixture/test installers as real downloads.
- Do not imply a module is commercially available merely because code exists.
- Do not imply support for a platform/version from a single development test.
